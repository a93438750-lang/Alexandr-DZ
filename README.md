# Домашняя работа: Автоматизация UI-тестов с Allure Report

## Описание проекта

Проект представляет собой набор автоматизированных UI-тестов, использующих библиотеку **Selenium** и систему отчетности **Allure**. Включает два сценария:

1. **Онлайн-магазин (Sauce Labs)**: Тестирует функциональность авторизации, добавления товаров в корзину и оформления заказа.
2. **Калькулятор**: Тестирует работу калькулятора с функцией задержки вычислений.

---

## Требования

Для запуска проекта вам понадобятся:

- **Python 3.x**
- **Библиотеки**: `pytest`, `allure-pytest`, `selenium`
- **Браузеры**: Google Chrome (и/или Firefox)
- **Веб-драйверы**: `chromedriver.exe` (и/или `geckodrive.exe`)

---

## Установка зависимостей

Установите необходимые пакеты через pip:
pip install pytest allure-pytest selenium


---

## Запуск тестов и формирование отчета

Чтобы запустить тесты и сформировать отчет Allure, выполните следующие команды в терминале:  bash

Запуск тестов и сохранение результатов в папку allure-results
pytest --alluredir=allure-results

Генерация HTML-отчета
allure generate allure-results --clean

Просмотр отчета в браузере
allure open


---

## Примечания

- **Папка `allure-results`**: содержит промежуточные данные для отчета. Не включайте её в репозиторий.
- **Папка `allure-report`**: создается автоматически при генерации отчета. Её также не нужно включать в репозиторий.
